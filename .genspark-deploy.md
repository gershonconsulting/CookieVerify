# CookieVerify.com - GenSpark Deployment Configuration

## Project Type
- **Frontend**: Static HTML/CSS/JavaScript
- **Backend**: Python Flask API
- **Architecture**: Dual-service (Web + API)

## Build Configuration
- **Build Command**: `echo "Build complete"`
- **Install Command**: `pip3 install -r requirements.txt`
- **Start Command**: `node start-server.js` or see Procfile

## Service Ports
- **Web Application**: Port 5060
- **API Server**: Port 5061

## Environment Variables
- `PORT`: 5061 (for API server)
- `FLASK_ENV`: production
- `ENVIRONMENT`: production

## Dependencies
- **Python**: 3.12+
- **Node.js**: 18+ (for deployment script only)
- **Python Packages**: See requirements.txt

## Health Checks
- **Web**: GET http://localhost:5060/
- **API**: GET http://localhost:5061/api/health

## Notes
This is a Python Flask application with static frontend.
GenSpark Hosted Deploy should use the Procfile or start-server.js to launch both services.
